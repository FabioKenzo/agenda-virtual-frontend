# 📅 Agenda Virtual - Frontend

Aplicação web para comunicação entre escola e responsáveis, desenvolvida como a interface do projeto **Agenda Virtual**.

## 🚧 Status do Projeto

![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-yellow)

Atualmente o projeto encontra-se na fase de **Setup e Estruturação de Componentes/Rotas**.

## 🎯 Objetivo

Oferecer uma interface moderna, responsiva e intuitiva para que responsáveis e gestão escolar possam acompanhar comunicados, agendas e eventos de forma rápida e centralizada.

---

## 🛠️ Tecnologias e Ferramentas

* **HTML5**
* **CSS3**
* **TypeScript**
* **Angular** (v17+)
* **Bootstrap** (Interface e Layout)
* **Bootstrap Icons** (Iconografia)
